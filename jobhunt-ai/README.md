# JobHunt AI

Personal AI-assisted job acquisition system.

MVP: profile config, public job feeds, deduplication, explainable ranking, review dashboard, and application tracking. Human approval is mandatory before any external application or message. No unauthorized LinkedIn scraping.

Stack: Python 3.12, FastAPI, Streamlit, PostgreSQL, SQLAlchemy, Alembic, Pydantic, httpx, pytest.

See `docs/DEVELOPMENT_PLAN.md`.
